# Movie Match Web v1.3.1

Frontend-only update based on Movie Match Web v1.3.

Changes:
- compact rounded genre chips restored below the movie description;
- right information panel can grow naturally without stretching the trailer/action area;
- removed the large background panel behind reaction buttons;
- added delayed hover/focus tooltips for dislike, skip and like actions;
- backend is intentionally not included in this archive.

Run from the monorepo root:

```bash
corepack pnpm install
corepack pnpm dev:web
```
