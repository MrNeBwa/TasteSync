# ADR-001 — Initial architecture

## Decision
Use a modular monolith backend with React web, React Native mobile, PostgreSQL, Redis and WebSocket realtime.

## Why
- Fast iteration for MVP.
- Shared TypeScript domain contracts.
- Avoid premature microservice operational cost.
- WebSocket is sufficient for room/session realtime.

## Boundaries
- `auth`
- `users`
- `rooms`
- `movies`
- `sessions`
- `voting`
- `matching`

## Future extraction candidates
Only extract a service when scaling or team ownership justifies it, likely movie ingestion and notifications first.
